# БЕЛ Мастър — сайт

Уеб версията на БЕЛ Мастър: подготовка за матурите по БЕЛ (7., 10. и 12. клас) с мини тестове,
цели матури, библиотека, приятели и мултиплейър битки за територии.

## Структура

```
apps/web        Next.js сайтът (страници, вход, тестове, библиотека, админ)
apps/game       игровият сървър (Socket.IO) — единственият, който решава кой печели
packages/db     схемата на базата (PostgreSQL + Prisma), импорт на въпроси
packages/shared общи типове, правила, карти
data/matura     PDF-и на матурите (7-klas, 10-klas, 12-klas)
data/questions  обработените въпроси (JSON) — виж data/questions/README.md
data/works      списъци с произведения
data/demo       демо въпроси (само за проба)
scripts         генератор на картите
deploy          пример за Caddy на VPS
```

## Локално пускане (с Docker)

```bash
cp .env.example .env
docker compose up -d --build
SEED_DEMO=1 docker compose run --rm setup   # таблици + произведения + демо въпроси
```

Сайт: http://localhost:3000 · игрови сървър: http://localhost:4000/health

Без `SEED_DEMO=1` се зареждат само произведенията и истинските въпроси от `data/questions`.

## Локално пускане (без Docker)

Нужни са Node 22 и PostgreSQL 16.

```bash
npm install
cp .env.example .env              # оправи DATABASE_URL
npm run db:push                   # създава таблиците
npm run db:seed:demo              # или db:seed без демо въпросите
npm run dev                       # сайт :3000 + игрови сървър :4000
```

## Правила на битката

- 2–4 играчи, само от един и същи клас. 1 на 1 → малка карта (12 области), 3–4 → голяма (20 области).
- **Класическа битка** — случайни въпроси; **Битка на произведенията** — всяко поле е творба и
  въпросът е за нея (когато въпросите за нея свършат — случаен).
- Всеки има **столица** с 3 живота. Превземеш ли я — взимаш всичките области на собственика.
- Първо **разпределяне**: всички отговарят, най-бързите верни избират свободна област.
- После **12 кръга** атаки: нападателят и защитникът отговарят на един въпрос (40 сек. за избор, повече за другите типове). Верният
  печели; ако и двамата са верни — по-бързият. Ако никой не е верен — нищо не се случва.
- Притежаваш ли цяла **земя** (група области) — 2 атаки на ход.
- Жокери: 50/50 и +5 сек. (по веднъж на игра). Изпаднал играч има 30 сек. да се върне.
- Печели който завладее всичко, иначе след 12 кръга — който има най-много области.
- Рейтинг (Elo) — отделен за всеки клас, месечен сезон + за всички времена. Гостите и игрите срещу бот са без рейтинг.

## VPS

`docker compose up -d --build` на сървъра + Caddy пред него (виж `deploy/Caddyfile`).
В `.env` смени `APP_URL`, `NEXT_PUBLIC_GAME_URL`, `GAME_JWT_SECRET` и `POSTGRES_PASSWORD`.
