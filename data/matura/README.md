# Матури (изходни PDF файлове)

Тук се слагат PDF файловете с минали матури и ключовете с верните отговори.

| Папка | Изпит |
|---|---|
| `7-klas/`  | НВО 7. клас |
| `10-klas/` | НВО 10. клас |
| `12-klas/` | ДЗИ 12. клас |

## Именуване (препоръчително)

```
<година>-<сесия>-izpit.pdf    напр. 2023-mai-izpit.pdf
<година>-<сесия>-kluch.pdf    напр. 2023-mai-kluch.pdf
```

## Как се обработват

Всеки въпрос от матурата се разпределя така:

- **Език** (граматика, лексика, правопис, пунктуация) → мини тестове „Език“ + мултиплейър
- **Литература** → мини тестове „Литература“ (случайни) + мултиплейър; всеки въпрос има етикет
  към конкретното произведение (или „общ“), за режим „Битка на произведенията“
- **Четене с разбиране** → само мини тестове „Четене“ (текстът се пази отделно), **не** в мултиплейъра
- **Есе, ЛИС, преразказ, теза** → не се взимат

Верните отговори се взимат от ключа. Всеки въпрос пази източника си (напр. „ДЗИ 2023, май, въпрос 14“).
Резултатът от обработката отива в `data/questions/<клас>/<година>-<сесия>.json`.
